# 🚀 Telephoto - Recent Feature Updates
*Last Updated: December 30, 2025*

This document outlines the latest features, optimizations, and changes implemented in the system.

## 1. 🐞 Advanced Bug Reporting System
A streamlined way for users to report issues, with instant team notification.

*   **User Dashboard**: New "Bug Report" page (`/dashboard/bug-report`) in the sidebar.
*   **Auto-Capture**: Automatically captures device info (Platform, Screen Size) to aid debugging.
*   **Direct-to-Telegram**: Reports are **NOT** stored in the database. They are formatted and sent directly to the Admin Telegram Channel via the bot.
*   **Rich Notifications**: Telegram alerts include User Name, Email, ID, Priority, Title, and Description.

## 2. 💳 Payment & Plan Upgrade Flow
Implemented a secure and restricted flow for plan upgrades to prevent unauthorized free upgrades.

*   **Restricted Access**: Users can no longer switch plans directly with a single click.
*   **Checkout Flow**: Clicking "Upgrade" redirects to a new **Mock Payment Page** (`/dashboard/payment`).
*   **Simulation**: Visual "Processing" animation and mock card details to simulate a real payment gateway.
*   **Plan Activation**: Plan is upgraded only after the "payment" process completes (Simulated for now, ready for Stripe integration).
*   **Admin Control**: Admins can manually override/change user plans via the **Admin Users Panel** (`/admin/users`) using the new "Plan" action button.

## 3. 🤖 Intelligent Telegram Bot Optimization
Enhancements to the core storage engine for faster retrieval and better reliability.

*   **Smart Retrieval**: System now stores *which* bot uploaded a file (`uploadedByBot`).
*   **Direct Linking**: CDN creates retrieval links directly from the uploader bot, eliminating "File not found" errors caused by querying the wrong bot.
*   **Send Message Capability**: Bots can now send formatted HTML text messages (used for Bug Reports).
*   **Removed Simulation**: The "Kill Bot" testing panel has been removed from the Admin UI for a cleaner, production-ready interface.

## 4. 🛡️ Admin Panel Enhancements
*   **Bug Reports View**: New informational page (`/admin/bugs`) explaining the Telegram delivery flow.
*   **Sidebar Navigation**: Added "Bug Reports" for quick access.
*   **User Management**: Added ability to upgrade/downgrade user plans directly from the user list.

## 🔗 Key API Changes
*   `POST /api/bug-report`: Accepts bug details + device info, validates session, sends Telegram notification.
*   `POST /api/user/plan`: Handles plan updates (now protected/called by payment page).
*   `GET /api/admin/bugs`: (Deprecated/Replaced) - Reports are now external (Telegram).
